# 哔哔啵啵（bibibobo）

把一句话变成小人说话的「哔哔啵啵」声。没有录音，没有 AI 配音，零依赖，浏览器和 Node 都能用。

这是 B 站 [哈基科技](https://space.bilibili.com/3707062397700195)《路墨小剧场》里大肥鱼和路墨的说话声，取自每期配乐脚本里的同一段代码。

## 直接玩

双击 `index.html` 用浏览器打开：输入一句话，选声线，点「说！」，也可以下载 WAV。网页不依赖别的文件，也不联网。

## 命令行

```bash
node cli.mjs "今天吃白饭？" out.wav
node cli.mjs "真没饭了。" lumo.wav --voice lumo
```

## 在代码里用

```js
import {synth, toWav} from './bibibobo.js';

const samples = synth('没饭了？没饭了！没饭了……', {voice: 'fish'}); // Float32Array，44.1 kHz 单声道
const wav = toWav(samples);                                          // Uint8Array，可以直接存成 .wav
```

`synth(text, opts)` 的选项：

| 选项 | 默认 | 说明 |
|---|---|---|
| `voice` | `'fish'` | `'fish'`（大肥鱼）、`'lumo'`（路墨），或传一个对象覆盖 `VOICES.fish` 里的参数 |
| `step` | 声线自带 | 每个字间隔多少秒（大肥鱼 0.13，路墨 0.16） |
| `gap` | `0.22` | 句子之间停多少秒 |
| `sampleRate` | `44100` | 采样率 |

## 它是怎么做的

1. **一条锯齿波。** 最普通的电子音。
2. **两个带通滤波器捏出口型。** 人说「啊」「衣」「呜」的区别，主要是两个共振峰频率不同。这里有五种口型，每种就是两个数（Hz）：`[800, 1200]`、`[400, 2200]`、`[350, 800]`、`[600, 1700]`、`[300, 2600]`。锯齿波只留下这两段，其余滤掉，听起来就像在张嘴。
3. **一个字一声。** 一个汉字算一声，一串英文或数字算一声。每个字用一个很小的哈希函数算出一个数，拿它去选音高和口型，所以同一个字永远是同一声。
4. **每个角色一组音阶。** 大肥鱼是 E5 G5 A5 B5 C6，路墨是 D4 E4 G4 A4。大肥鱼的共振峰整体乘 1.25（更尖），每个字开头还有一个很短的小滑音；路墨乘 0.9，句尾轻轻往下落。
5. **标点管语气。** 问号结尾，最后一个字往上滑 5 个半音；带感叹号，整句升高 3 个半音；省略号结尾，整句压低 3 个半音，最后一个字往下滑 4 个半音。

全部加起来不到一百行，都在 `bibibobo.js` 里，注释是中文的。

`index.html` 里嵌了一份 `bibibobo.js` 的原样拷贝。改了 `bibibobo.js` 之后运行 `node build.mjs` 同步过去。

## 和视频里的差别

- 视频里一句台词只套一条语气规则；这里会按标点把一段话切成几句，每句各套一条，方便直接输入长句。
- 视频里说话声还过了一点混响，和配乐一起做了限幅；这里只做了软限幅，没有混响。
- 想改声线，改 `VOICES` 里的音阶和 `formant` 就行；想加口型，往 `VOWELS` 里加一对频率。
